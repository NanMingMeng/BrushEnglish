# 常见问题（FAQ）

## 1. 启动时报 `WinError 10061 目标计算机积极拒绝`

说明脚本连不上本机的 OCR 服务。

处理顺序：

1. 点界面右上角的“重启引擎”，等状态变成绿色。
2. 如果还不行，把引擎切到 `Rapid`，等 5～20 秒再点“开始运行”。
3. 仍然失败：完全关闭助手再重新打开。
4. 使用外部 Umi-OCR 时，确认 Umi-OCR 已启动并开启 HTTP 服务（默认端口 1224）。

## 2. 按钮被窗口边缘挡住

窗口最窄支持 620 宽度。如果仍然拥挤：

- 把窗口拉宽到 1000 以上，按钮会显示完整文字。
- 或者把系统缩放调到 100% 再试。

## 3. 坐标对不上、点错位置

- 说明屏幕分辨率或缩放和坐标方案不匹配。
- 打开“坐标校准”页，重新校准并保存一套方案。
- 支持多套坐标方案，切换显示器或分辨率时切换方案即可。

## 4. 拼写题听不到声音

- 打开“试录”对话框，选择名字里带“扬声器”的设备。
- 确认系统音量不为 0，且 App 正在播放单词读音。
- 第一次录音可能只录到静音，脚本会自动点喇叭重播再听一次。
- 仍然不行时，把“听音”开关关掉，脚本会退回词表顺序。

## 5. 弹出“选择题没把握，请选 A/B/C/D”

说明脚本对选项没有足够把握，不会乱选，需要你拍板。

- 日志里会列出题目释义和四个选项。
- 输入 `a` / `b` / `c` / `d` 选择。
- 直接回车 = 选 A。
- 输入 `q` = 终止脚本。

## 6. 进度和 App 显示不一致

脚本启动时会用 App 上显示的 `x/30` 校准进度。

- 如果显示 `30/30` 但脚本还提示未完成，通常是上次保存的进度少了一题。
- 重新启动助手会自动按 App 显示校准。
- 仍然不对时，删除 `progress.json` 后重新开始（会丢失本地进度记录）。

## 7. 日志在哪里

- 默认在程序目录下的 `logs/run_YYYYMMDD.log`。
- 反馈截图在 `测试截图/反馈截图/`。

## 8. 会上传我的数据吗

不会。截图、录音、学习记录、日志都只保存在本机。项目没有遥测，也不会把数据发到服务器。

## 9. 项目能用于哪些 App

当前主要面向网页版背单词流程，通过坐标和图像识别操作。不同 App 的界面不同，不能保证通用。使用前请确认目标 App 允许自动化操作。

## 10. 为什么有时会停下来

脚本遇到无法自动恢复的问题时会停止，而不是乱点。日志会写明原因和建议检查项。
